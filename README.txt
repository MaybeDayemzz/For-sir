CAPITAL SCHOLARS WEBSITE
========================

Files
-----
- index.html          Main website
- style.css           Responsive styling and animations
- script.js           Mobile navigation, scroll reveals, service preselection and enquiry form
- assets/tutoring-hero.jpg   Cropped hero photo from the supplied flyer

How to use
----------
1. Extract the ZIP folder.
2. Keep the index.html, style.css, script.js and assets folder together.
3. Double-click index.html to open the website in your browser.

Contact actions

- Enquiry form opens WhatsApp to +923428837509 with the entered details.
